# Octree with nodes as spheres

## Installation

1. **Clone the repository**:

    ```bash
    git clone https://github.com/yourusername/octree.git
    cd octree
    ```

2. **Create a virtual environment**:

    ```bash
    python -m venv venv
    source venv/bin/activate  # On Windows use `venv\Scripts\activate`
    ```

3. **Install the dependencies**:

    ```bash
    pip install -r requirements.txt
    ```

4. **Create '.env' file in the project root directory**

## Usage

1. **upload .las file**:

    ```upload .las file into project root directory
    insert your .las file name into .env file:
    LAS_FILE=your_las_file_name.las
    ```

2. **Run the main script**:

    ```bash
    python src/main.py
    ```
